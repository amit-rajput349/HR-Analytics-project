# HR Analytics Project

This project analyzes HR data to understand employee attrition, 
performance, salary, and hiring trends.

## Features
- Employee Attrition Analysis
- Department-wise Performance
- Salary Distribution
- Hiring & Retention Trends
- Interactive Dashboard

## How to Run
1. Download this project
2. Open the file
3. Run the code / Open Dashboard
